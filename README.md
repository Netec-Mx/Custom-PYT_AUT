# Python orientado a automatización

Curso práctico que enseña uso de Python para automatizar tareas diarias, integrar sistemas y procesar datos, enfocando en soluciones aplicables y escalables en entornos laborales.

## Estructura

- `CapituloXX/README.md`: guía de laboratorio por capítulo.

## Lista de laboratorios

### Capítulo 1

- [Configuración del entorno y primer script de automatización](Capitulo01/README.md#configuración-del-entorno-y-primer-script-de-automatización)
  - Descripción: Configuración del entorno y ejecución del primer script de automatización a partir de los elementos abordados en el capítulo.
  - Duración estimada: 24 min

### Capítulo 2

- [Procesamiento de archivos JSON y CSV](Capitulo02/README.md#procesamiento-de-archivos-json-y-csv)
  - Descripción: Procesamiento de archivos JSON y CSV utilizando las estructuras de datos y transformaciones abordadas en el capítulo.
  - Duración estimada: 32 min

### Capítulo 3

- [Biblioteca reutilizable para automatización](Capitulo03/README.md#biblioteca-reutilizable-para-automatización)
  - Descripción: Construcción de una biblioteca reutilizable para automatización mediante funciones, modularización y librerías estándar tratadas en el capítulo.
  - Duración estimada: 32 min

### Capítulo 4

- [Automatización de respaldos y limpieza de archivos](Capitulo04/README.md#automatización-de-respaldos-y-limpieza-de-archivos)
  - Descripción: Automatización de respaldos y limpieza de archivos integrando lectura y escritura, manejo de rutas, procesos, excepciones y logging.
  - Duración estimada: 38 min

### Capítulo 5

- [Automatización mediante APIs REST](Capitulo05/README.md#automatización-mediante-apis-rest)
  - Descripción: Automatización mediante APIs REST aplicando consumo de servicios, serialización JSON, autenticación, manejo de errores HTTP y diseño reutilizable.
  - Duración estimada: 38 min

### Capítulo 6

- [Generación automática de reportes](Capitulo06/README.md#generación-automática-de-reportes)
  - Descripción: Generación automática de reportes mediante procesamiento, validación, limpieza y exportación de datos en formatos tabulares.
  - Duración estimada: 38 min

### Capítulo 7

- [Automatización completa con alertas](Capitulo07/README.md#automatización-completa-con-alertas)
  - Descripción: Construcción de una automatización completa con programación de tareas, notificaciones, envío de correos y estrategias de reintentos.
  - Duración estimada: 38 min

### Capítulo 8

- [Automatización de una aplicación web](Capitulo08/README.md#automatización-de-una-aplicación-web)
  - Descripción: Automatización de una aplicación web aplicando Selenium, interacción con formularios y registro y monitoreo de la ejecución.
  - Duración estimada: 38 min

### Capítulo 9

- [Depuración y pruebas de un script real](Capitulo09/README.md#depuración-y-pruebas-de-un-script-real)
  - Descripción: Depuración y pruebas de un script real utilizando debugging, breakpoints, logging, trazabilidad, pruebas unitarias, validaciones y manejo de errores.
  - Duración estimada: 38 min

### Capítulo 10

- [Empaquetado y despliegue de un proyecto](Capitulo10/README.md#empaquetado-y-despliegue-de-un-proyecto)
  - Descripción: Empaquetado y despliegue de un proyecto aplicando documentación técnica, control de versiones, distribución, seguridad, escalabilidad y mantenimiento.
  - Duración estimada: 42 min
