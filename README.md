# Python orientado a automatización

## Plataforma de laboratorios

Te damos la bienvenida a la **plataforma de laboratorios** del curso
**Python orientado a automatización**. Aquí podrás explorar diferentes
tecnologías y técnicas de automatización con Python a través de
prácticas guiadas. ¡Desarrolla tus habilidades y lleva tus conocimientos
al siguiente nivel!

## Lista de laboratorios

Cada uno de estos laboratorios está diseñado para ofrecerte una
experiencia práctica. Haz clic en los enlaces para comenzar.

### [Práctica 1. Configuración del entorno y primer script de automatización](Capitulo01/README.md)

-   **Descripción**: Preparar un entorno profesional de Python y
    desarrollar un script que inspeccione un proyecto, compruebe la
    existencia de carpetas y archivos obligatorios, y reporte de forma
    clara cuáles elementos existen, cuáles faltan y si cada elemento
    encontrado tiene el tipo esperado.
-   ⏱️ **Duración estimada**: 35 min.

### [Práctica 2. Procesamiento de archivos JSON y CSV](Capitulo02/README.md)

-   **Descripción**: Desarrollar un programa en Python que cargue
    registros de equipos desde archivos CSV y JSON, normalice sus datos,
    elimine duplicados, permita filtrar por estado, área o sistema
    operativo y genere estadísticas básicas mediante listas,
    diccionarios, sets y comprehensions.
-   ⏱️ **Duración estimada**: 40 min.

### [Práctica 3. Biblioteca reutilizable para automatización](Capitulo03/README.md)

-   **Descripción**: Construir un paquete de funciones reutilizables
    para crear directorios, listar archivos, validar extensiones,
    calcular tamaños y generar nombres nuevos; posteriormente,
    utilizarlo desde un script principal que procese una carpeta y
    produzca un inventario.
-   ⏱️ **Duración estimada**: 35 min.

### [Práctica 4. Automatización de respaldos y limpieza de archivos](Capitulo04/README.md)

-   **Descripción**: Desarrollar una solución en Python que copie
    archivos importantes desde una carpeta de trabajo hacia una
    estructura de respaldo organizada por fecha, preserve metadatos,
    controle errores por archivo y registre cada operación en un log
    rotativo.
-   ⏱️ **Duración estimada**: 50 min.

### [Práctica 5. Automatización mediante APIs REST](Capitulo05/README.md)

-   **Descripción**: Desarrollar un cliente en Python que lea una lista
    de códigos de país, consulte la API pública del Banco Mundial
    mediante HTTP, valide las respuestas JSON, seleccione solamente los
    campos relevantes y almacene un resultado consolidado con manejo de
    errores.
-   ⏱️ **Duración estimada**: 50 min.

### [Práctica 6. Generación automática de reportes](Capitulo06/README.md)

-   **Descripción**: Construir un pipeline con pandas que cargue tickets
    desde CSV, valide columnas, limpie valores faltantes y duplicados,
    normalice categorías, clasifique incidencias, calcule indicadores y
    exporte resultados a CSV y Excel con varias hojas.
-   ⏱️ **Duración estimada**: 50 min.

### [Práctica 7. Automatización completa con alertas](Capitulo07/README.md)

-   **Descripción**: Desarrollar una automatización que revise
    periódicamente una carpeta, detecte archivos nuevos, procese
    solamente formatos permitidos, conserve un estado para evitar
    reprocesos, registre toda la actividad y emita una notificación de
    escritorio en Ubuntu.
-   ⏱️ **Duración estimada**: 50 min.

### [Práctica 8. Automatización de una aplicación web](Capitulo08/README.md)

-   **Descripción**: Automatizar con Selenium la navegación en una
    página pública de demostración, localizar una tabla mediante
    selectores estables, extraer sus filas, ordenar resultados y guardar
    un CSV, un resumen JSON, capturas de pantalla y logs como evidencias
    de ejecución.
-   ⏱️ **Duración estimada**: 55 min.

### [Práctica 9. Depuración y pruebas de un script real](Capitulo09/README.md)

-   **Descripción**: Diagnosticar y corregir un procesador de CSV y un
    cliente de API que contienen errores de rutas, normalización,
    validación, excepciones y resultados; utilizar breakpoints de VS
    Code y crear pruebas unitarias deterministas para evitar
    regresiones.
-   ⏱️ **Duración estimada**: 55 min.

### [Práctica 10. Empaquetado y despliegue de un proyecto](Capitulo10/README.md)

-   **Descripción**: Transformar un script desarrollado previamente en
    un paquete instalable y reproducible: organizar módulos con
    estructura `src`, externalizar configuración y credenciales,
    documentar instalación y ejecución, definir dependencias, preparar
    Git, construir artefactos y verificar la instalación en un entorno
    virtual limpio.
-   ⏱️ **Duración estimada**: 60 min.
